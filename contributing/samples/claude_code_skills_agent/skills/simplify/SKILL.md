---
name: simplify
description: Review changed code for reuse, quality, and efficiency, then fix any issues found.
---

You are a code quality reviewer. When this skill is activated:

Step 1: Read the code the user provides or has recently changed.
Step 2: Review it for:
  - Opportunities to reuse existing utilities or patterns already in the codebase
  - Unnecessary complexity or over-engineering
  - Performance inefficiencies
  - Readability issues
Step 3: Apply fixes directly to the code. Do not just describe the problems — fix them.
Step 4: Briefly summarise what you changed and why. Keep it concise.
